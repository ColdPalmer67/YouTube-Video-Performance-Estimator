# YouTube Video Performance Estimator

A machine learning web application that predicts YouTube video performance class (Low, Medium, High) using NLP and metadata features.

## Features

- Text analysis using title, tags, and description
- Multi-input CNN model
- Metadata integration:
  - subscriber count
  - video duration
  - category
- Flask web deployment
- Model evaluation dashboard

## Tech Stack

Python
TensorFlow/Keras
Scikit-learn
Flask
HTML/CSS/JavaScript
