YouTube Video Performance Estimator

Predict whether a video will land Low, Medium, or High before it publishes, using a CNN trained on title, tag, description, and metadata signals.

About this project

This tool takes basic video details (title, tags, description, subscriber count, duration, and category) and predicts an expected performance class based on a machine learning model trained on YouTube video data.
