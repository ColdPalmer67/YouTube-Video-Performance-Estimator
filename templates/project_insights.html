Overview & dataset collection

This project estimates how well a YouTube video is likely to perform before it's published. It combines natural language processing over the title, tags, and description with structured metadata — subscriber count, duration, and category — feeding both into a convolutional neural network that outputs one of three performance classes: Low, Medium, or High.

04

Evaluation, challenges & future scope

Model selection was informed by exploratory data analysis, a Chi-square test of independence between category and performance class, accuracy comparisons across all three candidate models, confusion matrices for per-class behavior, and training/validation curves to confirm convergence without overfitting.

View full charts → EDA, accuracy comparison, confusion matrices, and training curves.

Challenges encountered during development, and how each was addressed:

Overfitting
↓ addressed through
Dropout layers, early stopping, and monitoring validation performance to improve model generalization.
Class separation difficulty
↓ addressed through
Dataset balancing and improved category selection to create clearer performance patterns across Low / Medium / High classes.
Weak metadata contribution
↓ addressed through
Feature engineering and scaling to improve the usefulness of subscriber count, duration, and category information alongside text features.

Directions that would meaningfully extend the project beyond its current scope:

Larger dataset More videos per category for stronger generalization.
Transformer models Replace the CNN text branch with a transformer-based encoder.
Live YouTube API Pull real-time metadata instead of relying on manual entry.
Cloud deployment Host the model behind a scalable, production-grade endpoint.
Thumbnail analysis Add a vision branch that scores thumbnail effectiveness.
Improved UI/UX Continue refining the interface based on user feedback.
