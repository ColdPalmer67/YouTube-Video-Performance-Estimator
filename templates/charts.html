Charts & Model Evaluation

Exploratory data analysis and evaluation results supporting the CNN performance classifier used in this project.

Section 01

Exploratory Data Analysis

Before model training, the dataset was analyzed to understand how video category relates to performance class. A Chi-square test of independence was applied between category and performance class (Low / Medium / High). The test produced a statistically significant result (p < 0.05), indicating that video category is not independent of performance outcome — some categories are meaningfully more likely to fall into higher or lower performance classes than others.

Section 02

Predictive Model Evaluation

Three models were trained and compared to justify the final model choice. Logistic Regression served as a linear baseline over the scaled metadata features. Random Forest served as a stronger non-linear baseline capable of capturing feature interactions without deep learning. The final model, CNN V2, is a multi-input late-fusion convolutional network combining a text branch (title, tags, description) with a metadata branch (subscriber count, duration, category), and was selected as the deployed model based on its overall accuracy advantage below.

Section 03

Confusion Matrix Analysis

Confusion matrices show per-class prediction behavior for each model, revealing where each approach tends to confuse adjacent performance classes (e.g. Medium vs. High) rather than relying on accuracy alone.

Section 04

CNN Training Performance

Training and validation curves for the deployed CNN V2 model, used to confirm the model converged appropriately and to check for signs of overfitting between training and validation sets across epochs.
